# Неделя 4 · День 2 — Композабл useLocalStorage

**JS-разминка (10 мин):** `JSON.stringify` / `JSON.parse`, `localStorage` (`getItem`, `setItem`, `removeItem`). Что вернёт `getItem` для несуществующего ключа?

**Теория (15 мин):** ru.vuejs.org — примеры композаблов в документации (раздел «Композаблы»), FAQ по Composition API.

---

## Практика (30 мин) — в проекте `week-03-components/shop`

1. Создай `src/composables/useLocalStorage.js`:
   ```js
   const theme = useLocalStorage('theme', 'light')
   theme.value = 'dark' // сразу сохраняется в localStorage
   ```
   - возвращает `ref`;
   - при создании читает значение из `localStorage` по ключу, а если его нет — берёт `defaultValue`;
   - при любом изменении `ref` сохраняет новое значение (как JSON);
   - работает и с объектами/массивами (в том числе при изменении элемента внутри массива).
2. Используй его, чтобы список покупок из дня 5 прошлой недели переживал перезагрузку страницы.
3. Ещё пример: переключатель темы «светлая/тёмная», который запоминается.

## Мини-задачи

- Что будет, если в `localStorage` по ключу лежит испорченный JSON (`{abc`)? Сделай, чтобы композабл не падал, а брал `defaultValue` (вспомни `parseJSONSafe`).
- Открой страницу в двух вкладках. Бонус: синхронизируй их через событие `window` `storage`.
