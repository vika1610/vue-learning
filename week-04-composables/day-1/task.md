## Практика (30 мин) — в проекте `week-03-components/shop`

Композабл — функция, которая использует реактивность Vue (`ref`, `computed`, `watch`, хуки) и возвращает реактивные данные. По соглашению её имя начинается с `use`.

1. Создай `src/composables/useFetch.js`:
   ```js
   const { data, loading, error } = useFetch('https://jsonplaceholder.typicode.com/users')
   ```
   - `data` — загруженные данные (сначала `null`);
   - `loading` — `true`, пока идёт запрос;
   - `error` — текст ошибки или `null`.
   - Не забудь про `response.ok`!
2. Используй `useFetch` в **двух разных** компонентах с разными адресами: список пользователей и список постов (`/posts?_limit=5`). Покажи «Загрузка…» и ошибку.

## Мини-задачи

- Добавь в результат функцию `refetch()` — повторить запрос (кнопка «Обновить»).
- Бонус: пусть `useFetch` принимает не только строку, но и `ref` с адресом, и сам перезагружает данные при смене адреса (подсказка: `toValue` + `watchEffect`).
