# Неделя 4 · День 3 — ПРОЕКТ: старт «Трекера привычек»

**JS-разминка (10 мин):** объект `Date` — даты без времени, сравнение дней.
Попробуй в консоли: `new Date().toISOString().slice(0, 10)`. Почему вечером по московскому времени это может дать **вчерашнюю** дату? Как получить дату в местном часовом поясе в формате `ГГГГ-ММ-ДД`?

**Теория:** —. Сегодня весь час — на проект. Сначала прочитай [`habit-tracker/SPEC.md`](../../habit-tracker/SPEC.md) целиком.

## Практика

1. **Модель данных.** Прочитай модель привычки в SPEC.md. Напиши на бумаге 2–3 привычки в этом формате. Ответь себе: почему `doneDates` хранит строки `"2026-10-05"`, а не объекты `Date`?
2. **Набросок экранов на бумаге.** Нарисуй от руки 4 экрана: «Сегодня», «Все привычки», «Страница привычки», «Статистика». Отметь, какие кнопки и поля где. Сфотографируй и положи в `habit-tracker/sketches/`.
3. **Создай проект:**
   ```bash
   cd habit-tracker
   npm create vue@latest
   ```
   - имя проекта: `app` (проект появится в `habit-tracker/app`);
   - TypeScript, Router, Pinia, Vitest — **нет** (добавишь на неделях 5–7 сама — это часть обучения);
   - ESLint/Prettier — по желанию.
4. Удали шаблонный код, выведи заголовок «Трекер привычек».
5. Создай `src/utils/date.js` с функцией `todayKey()` → строка `ГГГГ-ММ-ДД` для **сегодняшнего** дня в местном часовом поясе.
6. Закоммить.
