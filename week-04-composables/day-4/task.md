## Практика

1. Компонент `HabitForm.vue`:
   - поля «Название» и «Категория» (категория пока — простое текстовое поле или `<select>` из 3–4 вариантов);
   - пустое название не добавлять;
   - при отправке — событие `add` с данными; форма очищается.
2. Компонент `HabitList.vue` + `HabitItem.vue`: список привычек (название, категория).
3. В `App.vue` — массив привычек (`ref([])`). При событии `add` создаётся привычка по модели из SPEC:
   `id` — `crypto.randomUUID()`, `doneDates` — `[]`, `createdAt` — `todayKey()`.
4. Если привычек нет — сообщение «Добавь первую привычку».
5. Закоммить.
