# Неделя 3 · День 1 — Свой проект на Vite

**Цель недели:** перейти из песочницы в настоящий проект и научиться разбивать интерфейс на компоненты.

**JS-разминка (10 мин):** ES-модули, npm и `package.json` — что такое `dependencies` и `devDependencies`, что делает `npm install` и откуда берётся папка `node_modules`.

**Теория (15 мин):** ru.vuejs.org — «Быстрый старт» (раздел про локальный проект), однофайловые компоненты (SFC).

---

## Практика (30 мин)

1. Проверь, что Node.js установлен: `node -v` (нужна версия 20 или новее).
2. Перейди в эту папку и создай проект:
   ```bash
   cd week-03-components
   npm create vue@latest
   ```
   - имя проекта: `shop`;
   - TypeScript — **нет**; Router, Pinia, Vitest и прочее — **нет** (подключим, когда дойдём до них);
   - ESLint/Prettier — по желанию.
3. Зайди в проект, установи зависимости и запусти:
   ```bash
   cd shop
   npm install
   npm run dev
   ```
4. Открой адрес из терминала. Изучи, какие файлы создались: `index.html`, `src/main.js`, `src/App.vue`, `src/components/`.
5. **Удали шаблонный код:** всё из `App.vue`, компоненты-примеры в `src/components/`, лишние стили. Выведи свою страницу — например, заголовок «Мой магазин» и пару строк о себе.
6. Установи **Vue DevTools** — расширение браузера (Chrome / Firefox). Открой DevTools браузера → вкладка Vue, найди свой компонент.
7. Закоммить проект в git.

## Мини-задачи

- Найди в `package.json`, какие команды есть в `scripts`. Запусти `npm run build` — что появилось в папке `dist`?
- Поменяй порт dev-сервера в `vite.config.js` (опция `server.port`) и перезапусти.

## Проверь себя

- Что лежит в папке `src` и что делает `main.js`?
- Чем `.vue`-файл отличается от `.js`? Какие три блока в нём бывают?
