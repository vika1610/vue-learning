# Неделя 3 · День 3 — События компонента (emits)

**JS-разминка (10 мин):** callback-функции, паттерн «событие» (вспомни `addEventListener` из недели 0, день 4).

**Теория (15 мин):** ru.vuejs.org — «События компонента» (emits).

---

## Практика (30 мин) — в проекте `shop`

Данные идут **вниз** через props, а сообщения — **вверх** через события.

1. Создай компонент `src/components/ShoppingItem.vue`. Props: `text` (строка), `bought` (булево).
2. Внутри — текст покупки, чекбокс/кнопка «Куплено» и кнопка «Удалить».
3. **Компонент сам не меняет данные!** Вместо этого он отправляет родителю события:
   - `toggle` — при клике на «Куплено»;
   - `remove` — при клике на «Удалить».
4. В `App.vue` (или отдельной странице) — массив покупок и список `ShoppingItem`. Родитель слушает события и сам меняет массив.

## Мини-задачи

- Объяви события через `defineEmits(['toggle', 'remove'])` и посмотри, как это выглядит в Vue DevTools (вкладка Timeline → события компонентов).
- Передай с событием данные: `emit('remove', id)` — и прими их в родителе.
- Попробуй изменить prop прямо внутри `ShoppingItem` (`props.bought = true`) — что скажет Vue в консоли? Почему так нельзя?
