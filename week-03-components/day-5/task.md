# Неделя 3 · День 5 — Собираем список покупок из компонентов

**JS-разминка (10 мин):** повтор модулей — `export default` и именованный `export`, когда что.

**Теория (15 мин):** ru.vuejs.org — «Наследование атрибутов» (fallthrough attributes), `provide` / `inject` (обзор).

---

## Практика (30 мин) — в проекте `shop`

Перенеси «Список покупок» из `vue-exercises/src/exercises/week2/day2` в проект, разбив его на компоненты:

```
App.vue
└── ShoppingList.vue      — хранит массив покупок, считает оставшиеся
    ├── AddItemForm.vue   — поле + кнопка; отправляет событие add с текстом
    └── ShoppingItem.vue  — из дня 3 (toggle, remove)
```

И отдельно — `BaseButton.vue` с **вариантами**:

- prop `variant`: `'primary'` (зелёная), `'secondary'` (серая), `'danger'` (красная);
- текст кнопки — через слот;
- `BaseButton` используется во всех кнопках списка покупок (добавить — primary, удалить — danger).

## Мини-задачи

- Передай в `BaseButton` атрибут `disabled` или `type="submit"`, **не** объявляя его в props. Куда он попал? Это и есть наследование атрибутов.
- Через `provide` / `inject` передай из `App.vue` в `ShoppingItem` название валюты или цвет темы — без props на каждом уровне.
