# Изучение Vue.js за 9 недель

Учебный репозиторий по плану из [`Plan_Vue.pdf`](Plan_Vue.pdf): неделя 0 — база JavaScript, недели 1–8 — Vue. 5 дней в неделю по 1 часу. С 4-й недели — свой проект «Трекер привычек».

## Как устроен час

| 10 мин | 15 мин | 30 мин | 5 мин |
|---|---|---|---|
| JS-разминка | Теория по Vue | Практика: задача дня или шаг проекта | Заметка |

На неделе 0: 20 мин — тема, 35 мин — практика, 5 мин — заметка.

## Как пользоваться

1. Открой `PROGRESS.md` — там написано, какой сегодня день.
2. Прочитай условие задачи (`task.md` или комментарий сверху в `Exercise.vue`).
3. Решай сама. Застряла — открой `hints.md` рядом и смотри подсказки **по одной**.
4. Застряла дольше 20 минут — спроси наставника (Claude) и двигайся дальше.
5. В конце — заметка по шаблону [`notes/template.md`](notes/template.md), отметка в таблице ниже, коммит.

### Неделя 0 — JavaScript (`week-00-js/`)

Решения пишешь в `solution.js`, тесты лежат рядом в `solution.test.js`. Пока функция не написана, тесты красные — это нормально.

```bash
cd week-00-js
npm install          # один раз
npm run test:day1    # проверить день 1 (day2 … day5 — аналогично)
npm test             # все тесты недели
npm run test:watch   # перезапускать тесты при каждом сохранении
```

Дни 4 и 5 — ещё и страница в браузере: `npm run serve:day4`, `npm run serve:day5`.

### Недели 1, 2, 5, 6 — задачи по Vue (`vue-exercises/`)

```bash
cd vue-exercises
npm install          # один раз
npm run dev          # открой адрес из терминала — там меню со всеми задачами
```

Каждая задача — файл `src/exercises/weekN/dayN/Exercise.vue`: условие в комментарии сверху, заготовка с TODO внизу. Изменения видны в браузере сразу после сохранения. Задачи можно пробовать и в песочнице [play.vuejs.org](https://play.vuejs.org).

`vue-router` и `pinia` уже установлены, но подключаешь их ты сама — в `setup.js` рядом с задачами недель 5 и 6.

### Недели 3 и 4 (`week-03-components/`, `week-04-composables/`)

Условия и подсказки по дням. Проект для недели 3 создаёшь сама командой `npm create vue@latest` — инструкция в `week-03-components/day-1/task.md`.

### Проект «Трекер привычек» (`habit-tracker/`)

Техническое задание и шаги по дням — в [`habit-tracker/SPEC.md`](habit-tracker/SPEC.md). Код появится в `habit-tracker/app` на неделе 4.

## Правила, которые ускоряют обучение

- Набирай код руками, а не копируй. После примера из документации меняй его и смотри, что сломается.
- Застряла дольше 20 минут — задай вопрос и двигайся дальше.
- Не пропускай вопросы «Проверь себя».
- Коммить каждую задачу — это и дневник, и портфолио.
- Отставать нормально: лучше растянуть неделю, чем идти дальше с пробелами.
