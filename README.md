# Изучение Vue.js

Учебный репозиторий по плану из [`Plan_Vue.pdf`](Plan_Vue.pdf): неделя 0 — база JavaScript, недели 1–8 — Vue. С 4-й недели — свой проект «Трекер привычек».

## Темп: день плана = 2–3 занятия по часу

Исходный план рассчитан на 1 час в день, но с подробными конспектами и проверками день занимает 2–3 часа. Поэтому материал **не сокращается**, а делится на занятия:

- **Занятие** — 1 час, 5 раз в неделю.
- **День плана** (например, «Неделя 1 · День 3») — 2–3 занятия, в зависимости от сложности.
- В каждом конспекте (`theory.md`) вверху есть **📅 план занятий**, а в тексте — точки **🛑 Конец занятия N**. Дошла до 🛑 — на сегодня всё.
- Время в `task.md` и в условиях задач («Практика 30 мин») — из исходного плана, ориентируйся на план занятий в конспекте.
- Обучение займёт примерно **4–5 месяцев** вместо 9 недель. Это нормально: глубина важнее скорости.

### Как устроено одно занятие

| Тип занятия | Из чего состоит |
|---|---|
| **Теория** | 5 мин — вспомнить прошлое занятие → 40–45 мин — конспект до 🛑 → 5–10 мин — «Проверь себя» → 5 мин — заметка |
| **Практика** | 5 мин — перечитать условие → 45 мин — задача → 5 мин — проверка у наставника → 5 мин — заметка |

Правило часа: если время вышло на середине задачи — остановись, запиши в заметку, на чём остановилась, и продолжи в следующий раз.

## Как пользоваться

1. Открой `PROGRESS.md` — там написано, какой сейчас день и какое занятие.
2. Открой **конспект дня** (`theory.md`) и читай до ближайшего 🛑. Все конспекты по порядку — в [THEORY.md](THEORY.md).
3. Прочитай условие задачи (`task.md` или комментарий сверху в `Exercise.vue`).
4. Решай сама. Застряла — открой `hints.md` рядом и смотри подсказки **по одной**.
5. Застряла дольше 20 минут — спроси наставника (Claude) и двигайся дальше.
6. В конце — заметка по шаблону [`notes/template.md`](notes/template.md), отметка в таблице ниже, коммит.

### Неделя 0 — JavaScript (`week-00-js/`)

Решения пишешь в `solution.js`, тесты лежат рядом в `solution.test.js`. Пока функция не написана, тесты красные — это нормально.

```bash
cd week-00-js
npm install          # один раз
npm run test:day1    # проверить день 1 (day2 … day5 — аналогично)
npm test             # все тесты недели
npm run test:watch   # перезапускать тесты при каждом сохранении
```

Дни 4 и 5 — ещё и страница в браузере: `npm run serve:day4`, `npm run serve:day5`.

### Недели 1, 2, 5, 6 — задачи по Vue (`vue-exercises/`)

```bash
cd vue-exercises
npm install          # один раз
npm run dev          # открой адрес из терминала — там меню со всеми задачами
```

Каждая задача — файл `src/exercises/weekN/dayN/Exercise.vue`: условие в комментарии сверху, заготовка с TODO внизу. Изменения видны в браузере сразу после сохранения. Задачи можно пробовать и в песочнице [play.vuejs.org](https://play.vuejs.org).

`vue-router` и `pinia` уже установлены, но подключаешь их ты сама — в `setup.js` рядом с задачами недель 5 и 6.

Рядом с задачей лежат конспект `theory.md` и подсказки `hints.md`. Если есть `ExerciseOptions.vue` — это бонус: та же задача в стиле **Options API**, в меню у неё отдельная ссылка «Options API». Кнопка **«⏏ Размонтировать»** на странице задачи убирает компонент без перезагрузки — так проверяется `onUnmounted`.

### Недели 3 и 4 (`week-03-components/`, `week-04-composables/`)

Конспекты, условия и подсказки по дням. Проект для недели 3 создаёшь сама командой `npm create vue@latest` — инструкция в `week-03-components/day-1/task.md`.

### Проект «Трекер привычек» (`habit-tracker/`)

Техническое задание и шаги по дням — в [`habit-tracker/SPEC.md`](habit-tracker/SPEC.md), конспекты дней проекта — в [`habit-tracker/theory/`](habit-tracker/theory/). Код появится в `habit-tracker/app` на неделе 4.

## Правила, которые ускоряют обучение

- Набирай код руками, а не копируй. После примера из документации меняй его и смотри, что сломается.
- Застряла дольше 20 минут — задай вопрос и двигайся дальше.
- Не пропускай вопросы «Проверь себя».
- Коммить каждую задачу — это и дневник, и портфолио.
- Отставать нормально: лучше растянуть неделю, чем идти дальше с пробелами.
