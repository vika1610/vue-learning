# Занятие 1. Директивы и `v-bind`

## Разминка (5 мин): тернарный оператор и шаблонные строки

Что выведут строки, если `const hour = 21`?

```js
hour < 12 ? 'Доброе утро' : 'Добрый день'
`Сейчас ${hour} ч, ${hour >= 18 ? 'вечер' : 'день'}`
```

<details>
<summary>Ответ</summary>

1. `'Добрый день'`: 21 не меньше 12, поэтому берётся вариант после `:`.
2. `'Сейчас 21 ч, вечер'`: внутри `${}` можно писать любое выражение, даже тернарный оператор.

Сегодня обе вещи понадобятся прямо в шаблоне Vue.

</details>

## Часть 1. Директивы — «особые атрибуты» Vue

Вчера ты узнала, что `{{ }}` выводит значение **в текст** элемента, но в **атрибутах** не работает:

```vue
<img src="{{ photo }}">   ✗ браузер получит буквально "{{ photo }}"
```

Для атрибутов и вообще для всего, что «умнее» простого текста, во Vue есть **директивы**.

### Что такое директива

**Директива** — это специальный атрибут, который начинается с `v-`. Он говорит Vue: «сделай с этим элементом что-то особенное».

```vue
<img v-bind:src="photo">
<p v-if="isVisible">Привет</p>          <!-- неделя 2 -->
<li v-for="item in items">{{ item }}</li> <!-- неделя 2 -->
<button v-on:click="say()">Жми</button>  <!-- день 3 и неделя 2 -->
```

Сегодня — первая и самая частая: **`v-bind`**. Остальные будут дальше по курсу.

### Устройство директивы

```
v-bind:src="photo"
│      │    └── значение: JS-выражение (как в {{ }})
│      └── аргумент: к какому атрибуту привязать
└── имя директивы
```

⚠️ Главное, что нужно запомнить: **значение директивы в кавычках — это JavaScript, а не строка**. Внутри кавычек работают те же правила, что и в `{{ }}`: только **выражения**, не инструкции.

## Часть 2. `v-bind` — привязать атрибут к данным

### Зачем

Обычный HTML-атрибут — это всегда **фиксированная строка**:

```html
<a href="https://vuejs.org">Сайт Vue</a>
```

А если адрес лежит в переменной? Тогда нужен `v-bind`:

```vue
<script setup>
const docsUrl = 'https://ru.vuejs.org'
</script>

<template>
  <a v-bind:href="docsUrl">Документация</a>
</template>
```

Vue возьмёт **значение** переменной `docsUrl` и подставит его в атрибут `href`. В браузере получится `<a href="https://ru.vuejs.org">`.

### Короткая запись — двоеточие

`v-bind` используется так часто, что у него есть сокращение: просто `:`.

```vue
<a v-bind:href="docsUrl">Документация</a>
<a :href="docsUrl">Документация</a>      <!-- то же самое -->
```

На практике почти все пишут **короткую** запись. Встретишь `:что-то="..."` — это `v-bind`.

### ⚠️⚠️ С двоеточием и без — это совсем разные вещи

Самая частая ошибка дня:

```vue
<script setup>
const photo = 'https://i.pravatar.cc/150?img=3'
</script>

<template>
  <img src="photo">     <!-- ✗ src = буквально строка "photo" — картинки нет -->
  <img :src="photo">    <!-- ✓ src = значение переменной photo -->
</template>
```

| Запись | Что внутри кавычек | Результат |
|---|---|---|
| `src="photo"` | обычная **строка** | `src="photo"` |
| `:src="photo"` | **JS-выражение**: переменная | `src="https://i.pravatar..."` |

Если картинка не показывается или ссылка ведёт «не туда», первым делом проверь: **не забыто ли двоеточие?** Открой DevTools (F12) → вкладка Elements и посмотри, что на самом деле оказалось в атрибуте.

### В кавычках — любое выражение

Раз внутри `:атрибут="..."` — JavaScript, туда можно писать то же, что в `{{ }}`:

```vue
<script setup>
const user = 'anna'
const size = 200
</script>

<template>
  <!-- шаблонная строка -->
  <a :href="`https://github.com/${user}`">GitHub</a>

  <!-- арифметика -->
  <img :src="photo" :width="size / 2">

  <!-- тернарный оператор -->
  <img :alt="user ? `Фото ${user}` : 'Аноним'">
</template>
```

⚠️ Обрати внимание на **кавычки внутри кавычек**. Снаружи атрибута — двойные `"..."`, поэтому строки внутри пиши в одинарных `'...'` или обратных `` `...` ``. Иначе браузер решит, что атрибут закончился раньше времени:

```vue
<img :alt="'Аватар'">     ✓
<img :alt=""Аватар"">     ✗ атрибут закончился на второй кавычке
```

### ⚠️ Строку тоже можно передать через `:`, но в кавычках

```vue
<img :alt="Аватар">       ✗ ищет ПЕРЕМЕННУЮ Аватар — её нет
<img :alt="'Аватар'">     ✓ строка внутри выражения
<img alt="Аватар">        ✓ проще всего — без двоеточия, раз значение фиксированное
```

Правило: **значение фиксированное — пиши обычный атрибут. Значение из данных или вычисляется — `:`**.

### Числа и булевы значения

Без двоеточия **всё — строка**. С двоеточием сохраняется настоящий тип:

```vue
<input maxlength="10">     <!-- строка "10" — для HTML это нормально -->
<input :maxlength="10">    <!-- число 10 -->
```

Для обычных HTML-атрибутов разница почти незаметна. Но на неделе 3, когда ты начнёшь передавать данные в свои компоненты, это станет важно: `price="100"` передаст **строку**, а `:price="100"` — **число**.

### Что `v-bind` делает со «странными» значениями

```vue
<img :title="null">        <!-- атрибут title вообще не появится -->
<img :title="undefined">   <!-- тоже не появится -->
```

Если значение `null` или `undefined`, Vue **убирает** атрибут целиком. Удобно: можно не рисовать атрибут, если данных нет.

# Занятие 2. Данные-объекты в шаблоне и практика

## Часть 3. Объект с данными в шаблоне

### Много данных — удобно хранить объектом

В задаче сегодня у профиля много полей. Можно завести пять отдельных переменных, а можно собрать их в **один объект**: так данные одного профиля лежат вместе.

```vue
<script setup>
const book = {
  title: 'Дюна',
  author: 'Фрэнк Герберт',
  cover: 'https://picsum.photos/seed/dune/120/180',
  link: 'https://ru.wikipedia.org/wiki/Дюна_(роман)',
  available: true,
}
</script>

<template>
  <div class="book">
    <img :src="book.cover" :alt="`Обложка: ${book.title}`">
    <h2>{{ book.title }}</h2>
    <p>{{ book.author }}</p>
    <a :href="book.link">Подробнее</a>
    <p>{{ book.available ? 'есть в наличии' : 'нет в наличии' }}</p>
  </div>
</template>
```

Обращение к полям — через точку, как в обычном JS: `book.title`. И в `{{ }}`, и в `:атрибут`.

### ⚠️ Опечатка в имени поля

```vue
<h2>{{ book.titel }}</h2>   <!-- опечатка: поля titel нет -->
```

Чтение несуществующего свойства объекта даёт `undefined` (помнишь, `sheet['дом']` из разбора `reduce`?). Vue выведет **пустоту**, и на этот раз даже **без предупреждения** в консоли: сам объект `book` ведь существует. Такие опечатки ищи глазами или во Vue DevTools: там видно, какие поля есть у объекта.

### ⚠️ Если самого объекта нет

```vue
<h2>{{ user.name }}</h2>   <!-- а user не объявлен или равен undefined -->
```

Здесь будет уже **ошибка** (красная) `Cannot read properties of undefined (reading 'name')`, как в обычном JS. Компонент может вообще не отрисоваться. Полезно помнить: «пусто без ошибки» — скорее всего, опечатка в **поле**; «красная ошибка про undefined» — нет самого **объекта**.

### Булевы значения: тернарный оператор

Поле `available: true` на странице само по себе выведется как слово `true` — не очень красиво. Поэтому для булевых значений почти всегда нужен тернарный оператор, который превращает `true` / `false` в понятный текст. Ровно то, что было в разминке.

> На неделе 2 появится `v-if`: он позволит не только менять текст, но и показывать или скрывать целые блоки разметки.

## Часть 4. Атрибут `title` и другие полезные атрибуты

### `title` — всплывающая подсказка

Атрибут `title` есть у любого HTML-элемента: при наведении мышкой браузер показывает подсказку.

```vue
<div :title="`Книга: ${book.title}`">...</div>
```

Наведи курсор на элемент и подожди секунду — появится подсказка «Книга: Дюна».

### `alt` у картинок

`alt` — текст, который показывается, если картинка не загрузилась, и который читают программы для незрячих людей. Хорошая привычка: **у каждой `<img>` должен быть `alt`**, и лучше осмысленный: не «картинка», а «Обложка: Дюна».

### `target="_blank"` у ссылок

Чтобы ссылка открывалась в новой вкладке:

```vue
<a :href="book.link" target="_blank">Подробнее</a>
```

Обрати внимание: `target` фиксированный, поэтому без двоеточия, а `href` из данных — с двоеточием. В одном теге спокойно сочетаются оба вида атрибутов.

### Привязка нескольких атрибутов сразу (на будущее)

Если у тебя объект, где ключи совпадают с названиями атрибутов, можно привязать их **все сразу** — `v-bind` без аргумента:

```vue
<script setup>
const imgAttrs = { src: 'https://picsum.photos/100', alt: 'Случайное фото', width: 100 }
</script>

<template>
  <img v-bind="imgAttrs">   <!-- то же, что :src="..." :alt="..." :width="..." -->
</template>
```

Встречается не очень часто, но на неделе 3 этот приём пригодится, чтобы передать в компонент сразу все поля объекта.

### ⚠️ `class` и `style` — особые атрибуты

Через `:class` и `:style` тоже можно привязывать данные, но у них есть **свой удобный синтаксис** с объектами и массивами. Это отдельная большая тема дня 4, сегодня их не трогаем.

# Занятие 3. 📜 Options API

## Часть 5. 📜 Как это в Options API

### Хорошая новость: шаблон один и тот же

`v-bind`, `:`, `{{ }}`, кавычки внутри кавычек — **всё это часть шаблона**, а шаблон в обоих стилях одинаковый. Разница только в `<script>`.

**Composition API:**

```vue
<script setup>
const book = {
  title: 'Дюна',
  cover: 'https://picsum.photos/seed/dune/120/180',
}
</script>

<template>
  <img :src="book.cover" :alt="`Обложка: ${book.title}`">
</template>
```

**Options API:**

```vue
<script>
export default {
  data() {
    return {
      book: {
        title: 'Дюна',
        cover: 'https://picsum.photos/seed/dune/120/180',
      },
    }
  },
}
</script>

<template>
  <img :src="book.cover" :alt="`Обложка: ${book.title}`">
</template>
```

Объект `book` становится **одним из полей** объекта, который возвращает `data()`. Шаблон не меняется ни на символ.

### ⚠️ Вложенность скобок в `data()`

Самое частое затруднение при переписывании в Options API — запутаться в скобках:

```js
data() {          // 1. функция data
  return {        // 2. возвращает объект со ВСЕМИ данными компонента
    book: {       // 3. одно из данных — сам объект книги
      title: 'Дюна',
    },            // закрыли book
  }               // закрыли объект данных
},                // закрыли функцию data (запятая — дальше могут быть methods)
```

Подсказка: в VS Code с расширением Vue (Official) поставь курсор на скобку — подсветится её пара.

### Методы, которые собирают строки

Длинные выражения из `:атрибутов` можно вынести в методы. Помнишь правило: в методах Options API данные — только через `this`:

```js
export default {
  data() {
    return { book: { title: 'Дюна', author: 'Герберт' } }
  },
  methods: {
    coverAlt() {
      return `Обложка: ${this.book.title}`   // this.book, а не book
    },
  },
}
```

```vue
<img :src="book.cover" :alt="coverAlt()">
```

В Composition API это была бы обычная функция `function coverAlt() { return \`Обложка: ${book.title}\` }` — без `this`.

> На дне 4 появится `computed` — для таких «собранных» значений он подходит ещё лучше, чем метод. В Options API у него тоже есть своя опция.

### Как узнать `v-bind` в рабочем коде

В рабочих проектах встречаются все три записи, и все они означают одно и то же:

```vue
<img v-bind:src="url">   <!-- полная -->
<img :src="url">         <!-- короткая — самая частая -->
<img :src>               <!-- ещё короче (Vue 3.4+): если атрибут и переменная называются одинаково -->
```

Последний вариант — новинка Vue 3.4. Он значит `:src="src"`. Твой рабочий Vue 3.5 его поддерживает, так что можешь встретить.

|---|---|

| `class` и `style` | особый синтаксис — день 4 |
