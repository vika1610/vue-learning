# Подсказки · Неделя 1 · День 1 · Первое приложение

<details>
<summary>Подсказка 1 — намёк</summary>

Всё, что объявлено в `<script setup>`, автоматически доступно в шаблоне. Ничего экспортировать не нужно.

</details>

<details>
<summary>Подсказка 2 — конкретнее</summary>

Внутри `{{ }}` можно писать любое **выражение** JavaScript: переменную, арифметику, вызов метода строки. А вот `if` или `let` — нельзя, это не выражения.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

```vue
<script setup>
const name = '...'
const age = /* число */
</script>

<template>
  <p>Меня зовут {{ /* ? */ }}, мне {{ /* ? */ }} лет</p>
</template>
```

Через 5 лет: `{{ age + 5 }}`. Заглавными — вспомни метод строки `toUpperCase()`.

Пока обычные переменные работают, потому что значения не меняются во время работы страницы. Завтра-послезавтра узнаешь, зачем нужен `ref`.

</details>
