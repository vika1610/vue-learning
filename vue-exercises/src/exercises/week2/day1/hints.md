# Подсказки · Неделя 2 · День 1 · Список задач

<details>
<summary>Подсказка 1 — намёк</summary>

- `v-for` повторяет элемент для каждого элемента массива. `key` помогает Vue понять, какой элемент какой, — поэтому он должен быть **уникальным и постоянным** (подходит `id`, не подходит индекс).
- Пустой массив `[]` — это truthy! Как тогда проверить, что задач нет?

</details>

<details>
<summary>Подсказка 2 — конкретнее</summary>

- `<li v-for="task in tasks" :key="task.id">{{ task.text }}</li>`
- Пустой список: проверяй `tasks.length` (в шаблоне без `.value`).
- `v-if` и `v-else` должны стоять на **соседних** элементах.
- Подсказка: `const showHint = ref(false)`, кнопка меняет его на противоположное.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

```vue
<ul v-if="tasks.length">
  <li v-for="task in tasks" :key="task.id" :class="{ /* ? */ }">...</li>
</ul>
<p v-else>Список пуст</p>

<button @click="showHint = !showHint">Показать подсказку</button>
<p v-show="showHint">...</p>
```

Разница: `v-show` только прячет элемент через `display: none`, а `v-if` убирает его из страницы целиком.

Бонус: поменяй текст кнопки на «Скрыть подсказку», когда она открыта (тернарный оператор).

</details>
