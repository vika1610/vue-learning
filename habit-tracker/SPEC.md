# Трекер привычек — техническое задание

Проект делается с 4-й по 8-ю неделю. В итоге получится работа для портфолио, где использованы все изученные темы.

Код проекта будет в `habit-tracker/app` — его ты создашь сама на неделе 4, день 3 (`npm create vue@latest`).

> Альтернатива из плана, если хочется поработать с внешним API: поиск фильмов через TMDB API со списком «Хочу посмотреть». Если выберешь её — перепиши этот SPEC под фильмы до начала недели 4.

## Модель данных

Одна привычка:

| Поле | Тип | Пример | Зачем |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | уникальный ключ для `v-for`, адреса `/habits/:id` и поиска |
| `title` | `string` | `"Читать 20 минут"` | название |
| `category` | `string` | `"Здоровье"` | для группировки и фильтров |
| `doneDates` | `string[]` | `["2026-10-05", "2026-10-06"]` | дни, когда привычка выполнена |
| `createdAt` | `string` | `"2026-10-05"` | дата создания — для процента выполнения |

Даты хранятся строками `ГГГГ-ММ-ДД` **в местном часовом поясе**: их легко сравнивать через `===`, искать через `includes` и сортировать как строки.

Все привычки — массив таких объектов. На неделях 4–5 он живёт в `useLocalStorage('habits', [])`, с недели 6 — в Pinia-сторе.

## Страницы (с недели 5)

| Адрес | Страница | Что на ней |
|---|---|---|
| `/` | Сегодня | Привычки с отметкой «сделано сегодня», прогресс дня «3 из 5» |
| `/habits` | Все привычки | Список, добавление, редактирование, удаление; фильтр по категории (нед. 6) |
| `/habits/:id` | Страница привычки | Название, категория, дата создания, серия дней, история отметок |
| `/stats` | Статистика | Процент выполнения, лучшие серии; график (нед. 8) |
| `/:pathMatch(.*)*` | 404 | «Страница не найдена» |

## Шаги по дням

### Неделя 4 — Composition API, композаблы, старт проекта

| День | Шаг |
|---|---|
| 1–2 | (вне проекта) композаблы `useFetch` и `useLocalStorage` в проекте `shop` |
| 3 | Модель данных, набросок экранов на бумаге, создать проект `app`, утилита `todayKey()` |
| 4 | Форма добавления привычки (`HabitForm`) и список (`HabitList`, `HabitItem`) |
| 5 | «Сделано сегодня», редактирование, удаление, сохранение через `useLocalStorage` |

Подробно: `week-04-composables/day-3…day-5/task.md`.

### Неделя 5 — Vue Router

| День | Шаг |
|---|---|
| 1–4 | (вне проекта) задачи по роутеру в `vue-exercises` |
| 5 | Установить `vue-router` в проект. Страницы «Сегодня», «Все привычки», `/habits/:id`, «Статистика» (пока простая: сколько привычек, сколько выполнено сегодня), страница 404, меню навигации. Ленивая загрузка для «Статистики» |

> На этом шаге уровень 1 должен быть готов полностью.

### Неделя 6 — Pinia

| День | Шаг |
|---|---|
| 1–3 | (вне проекта) задачи по Pinia в `vue-exercises` |
| 4 | Установить `pinia`. Стор `habits`: state (массив привычек), getters (`todayList` — привычки с флагом «сделано сегодня», `streak(id)` — серия), actions (добавить, изменить, удалить, отметить). Сохранение в localStorage. Компоненты берут данные из стора, а не через props от `App.vue` |
| 5 | Категории (список категорий — getter), фильтр по категории на «Все привычки», подсчёт серии дней подряд и процента выполнения; показать на странице привычки и в «Статистике» |

Серия (streak): сколько дней подряд **до сегодня включительно** (или до вчера, если сегодня ещё не отмечено) привычка выполнена.
Процент выполнения: выполненные дни / дни с `createdAt` по сегодня.

### Неделя 7 — TypeScript, тесты, оформление

| День | Шаг |
|---|---|
| 1 | Подключить TypeScript. Типы `Habit` и `Category`, типизация props и emits (`lang="ts"`) |
| 2 | Перевести композаблы и стор на TypeScript (типизация `ref`, `computed`, стора) |
| 3 | Подключить Vitest. Вынести подсчёт серии в чистую функцию `calcStreak(doneDates, today)` и написать для неё тесты (пустой массив, сегодня отмечено / не отмечено, пропуск дня) |
| 4 | Vue Test Utils: тест `HabitItem` — клик по отметке → компонент отправил событие (`emitted`) |
| 5 | Оформление: Tailwind CSS **или** PrimeVue (выбрать одно), тёмная тема (`useDark` из VueUse), адаптив под телефон |

### Неделя 8 — завершение и деплой

| День | Шаг |
|---|---|
| 1 | Страница статистики с графиком выполнения (Chart.js + vue-chartjs): например, сколько привычек выполнено по дням за последние 14 дней |
| 2 | Улучшения: горячие клавиши, уведомления, анимации `<Transition>` / `<TransitionGroup>` для списка |
| 3 | `npm run build`, залить на GitHub с README и скриншотами, опубликовать на Netlify или Vercel |
| 4 | Lighthouse в Chrome DevTools, исправить баги, почистить код, проверить на телефоне |
| 5 | Подвести итоги и составить план, что изучать дальше (Nuxt, глубже TypeScript, бэкенд на Supabase/Firebase) |
