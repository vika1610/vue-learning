# Занятие 1. Раскладка

## Часть 1. Flexbox — элементы в ряд или столбик

```css
.toolbar {
  display: flex;
  gap: 8px;                     /* расстояние между элементами */
  align-items: center;          /* выравнивание поперёк */
  justify-content: space-between; /* распределение вдоль */
}
```

| Свойство | Что делает | Частые значения |
|---|---|---|
| `display: flex` | включить flex у **родителя** | |
| `flex-direction` | направление | `row` (ряд, по умолчанию), `column` (столбик) |
| `gap` | отступ между детьми | `8px`, `1rem` |
| `justify-content` | вдоль направления | `flex-start`, `center`, `space-between` |
| `align-items` | поперёк направления | `stretch`, `center`, `flex-start` |
| `flex-wrap: wrap` | переносить на новую строку, если не помещается | |
| `flex: 1` (у ребёнка) | занять всё свободное место | |

Где в трекере: строка привычки (галочка — название — кнопки), меню, шапка.

```css
.habit-row {
  display: flex;
  align-items: center;
  gap: 12px;
}
.habit-row .title {
  flex: 1;       /* название растягивается, кнопки прижаты вправо */
}
```

⚠️ `display: flex` пишется у **родителя**, а не у детей. Частая ошибка — поставить его самому элементу и удивляться, почему ничего не изменилось.

## Часть 2. Grid — сетка

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
}
```

Эта строка — «столько колонок, сколько поместится, каждая не уже 220px». На широком экране — четыре колонки, на телефоне — одна. **Без медиазапросов!**

| Свойство | Что делает |
|---|---|
| `display: grid` | включить сетку у родителя |
| `grid-template-columns: 1fr 1fr` | две равные колонки |
| `grid-template-columns: 200px 1fr` | боковая колонка 200px + остальное |
| `repeat(auto-fill, minmax(220px, 1fr))` | адаптивные колонки |
| `gap` | отступы между ячейками |

`1fr` — «одна доля свободного места».

### Flex или Grid

- **Flex** — для **одного ряда** или столбика: меню, кнопки, строка привычки;
- **Grid** — для **сетки** в двух направлениях: карточки, раскладка страницы.

Часто их сочетают: страница — grid, внутри карточки — flex.

## Часть 3. Адаптив: «сначала мобильный»

### Медиазапросы

```css
.page {
  padding: 12px;           /* для телефона — по умолчанию */
}

@media (min-width: 768px) {
  .page {
    padding: 32px;         /* для экранов от 768px и шире */
    max-width: 720px;
    margin: 0 auto;
  }
}
```

Подход **«сначала мобильный»** (mobile first): основные стили — для узкого экрана, а `@media (min-width: …)` **добавляет** изменения для широких. Так проще: на телефоне раскладка самая простая (всё в столбик), и её не нужно «переламывать».

### Обязательная строка

В `index.html` должна быть (create-vue её добавляет):

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Без неё телефон покажет страницу как «уменьшенный компьютерный сайт».

### Проверить на телефоне, не имея телефона

DevTools → кнопка с телефоном и планшетом (**Toggle device toolbar**, Ctrl + Shift + M) → выбери, например, iPhone. А на настоящем телефоне — на неделе 8, после деплоя.

### ⚠️ Частые проблемы на телефоне

- **горизонтальная прокрутка**: что-то шире экрана. Обычно — картинка или таблица без `max-width: 100%`, или фиксированная `width: 500px`;
- **мелкие кнопки**: палец промахивается. Минимум ~44×44px для всего, что нажимают;
- **мелкий текст в полях ввода**: если шрифт `input` меньше 16px, iPhone при фокусе **приближает** страницу.

# Занятие 2. Тёмная тема

## Часть 4. CSS-переменные

```css
:root {
  --color-bg: #ffffff;
  --color-text: #222222;
  --color-accent: #42b883;
  --radius: 12px;
}

body {
  background: var(--color-bg);
  color: var(--color-text);
}

.button {
  background: var(--color-accent);
  border-radius: var(--radius);
}
```

- `--имя: значение` — объявить переменную. `:root` — для всей страницы;
- `var(--имя)` — использовать.

Плюс: поменяла `--color-accent` в **одном** месте — поменялся цвет всех кнопок, ссылок, галочек.

### Переменные можно переопределить

```css
.danger-zone {
  --color-accent: #e53935;   /* внутри этого блока «акцент» — красный */
}
```

Переменная действует на элемент и **всех его потомков**. Это главный секрет тёмной темы.

## Часть 5. Тёмная тема на переменных

### Идея

Все цвета — через переменные. Для тёмной темы — **те же** переменные с другими значениями, когда на `<html>` висит класс `dark`:

```css
:root {
  --color-bg: #ffffff;
  --color-surface: #f5f5f5;
  --color-text: #222222;
  --color-muted: #666666;
}

:root.dark {
  --color-bg: #121212;
  --color-surface: #1e1e1e;
  --color-text: #eeeeee;
  --color-muted: #aaaaaa;
}
```

Добавила класс `dark` на `<html>` — **все** цвета на странице поменялись разом. Компоненты ничего не знают о теме: они просто используют `var(--color-text)`.

Это ответ на вопрос недели «Как работает тёмная тема через CSS-переменные?».

### ⚠️ Захардкоженные цвета

```css
.card { background: white; }   /* ⚠️ в тёмной теме останется белым пятном */
```

Найди все цвета в стилях компонентов (поиск по `#` и `rgb` в `.vue`-файлах) и замени на переменные.

### Тема системы

Браузер знает, какую тему выбрал пользователь в настройках системы:

```css
@media (prefers-color-scheme: dark) {
  /* … */
}
```

## Часть 6. `useDark` из VueUse

**VueUse** — большая коллекция готовых композаблов (подробно — неделя 8). `useDark` делает для тёмной темы всё сразу:

```bash
npm install @vueuse/core
```

```vue
<script setup lang="ts">
import { useDark, useToggle } from '@vueuse/core'

const isDark = useDark()             // ref<boolean>
const toggleDark = useToggle(isDark) // функция-переключатель
</script>

<template>
  <button @click="toggleDark()">{{ isDark ? '☀️' : '🌙' }}</button>
</template>
```

Что делает `useDark`:
- при старте берёт тему **системы** (`prefers-color-scheme`);
- ставит или убирает класс **`dark`** на `<html>` — ровно тот, на который настроены переменные из части 5;
- **запоминает** выбор в `localStorage` — как твой `useLocalStorage`!

Это композабл, похожий на те, что ты писала сама на неделе 4 — только готовый.

# Занятие 3. UI-библиотека

## Часть 7. Tailwind CSS или PrimeVue

По плану нужно выбрать **одно**. Это два разных подхода:

| | **Tailwind CSS** | **PrimeVue** |
|---|---|---|
| Что это | набор **утилитарных классов** | набор **готовых компонентов** |
| Как выглядит | `<button class="px-4 py-2 rounded bg-green-500 text-white">` | `<Button label="Сохранить" />` |
| Внешний вид | рисуешь сама из «кирпичиков» | готовый дизайн, настраиваются темы |
| Сложные элементы (календарь, выпадающий список с поиском, таблица) | делать самой | есть готовые |
| Тёмная тема | классы `dark:`; работает с `useDark` | встроенные темы |
| Чему научит | CSS и вёрстке | работе с компонентной библиотекой (как во многих рабочих проектах) |

### Как выбрать

- Хочешь лучше понимать **CSS** и полностью контролировать вид → **Tailwind**;
- хочешь быстро получить **красивый интерфейс** и потренироваться с библиотекой компонентов → **PrimeVue**;
- **посмотри, что используется на работе**: если там есть UI-библиотека (PrimeVue, Element Plus, Vuetify, Quasar…) — выбери её или похожую.

### Установка

Обе библиотеки часто меняют шаги установки между версиями, поэтому **бери инструкцию с официального сайта** (раздел «Installation» → «Vite» / «Vue»), а не из старых статей. Если что-то не получится — пришли наставнику текст ошибки.

### Tailwind — пример

```vue
<div class="flex items-center gap-3 p-3 rounded-xl bg-white dark:bg-neutral-800">
  <input type="checkbox" class="w-5 h-5">
  <span class="flex-1">{{ habit.title }}</span>
</div>
```

`flex`, `items-center`, `gap-3` — это ровно Flexbox из части 1, только классами. А `dark:bg-neutral-800` — стиль для тёмной темы.

### PrimeVue — пример

```vue
<script setup lang="ts">
import Checkbox from 'primevue/checkbox'
import Button from 'primevue/button'
</script>

<template>
  <Checkbox v-model="checked" binary />
  <Button label="Удалить" severity="danger" @click="remove" />
</template>
```

Обрати внимание: `v-model` на компоненте библиотеки работает ровно так, как ты делала в `BaseInput` (неделя 3, день 4). А `severity="danger"` — prop варианта, как у твоего `BaseButton`.

### ⚠️ Свои базовые компоненты и библиотека

Если у тебя есть `BaseButton`, можно **внутри** него использовать кнопку библиотеки. Тогда остальной код не меняется, а внешний вид — новый. Это ещё один плюс базовых компонентов.

## Часть 8. 📜 Как это в Options API

CSS, переменные, медиазапросы и классы Tailwind — **не зависят** от стиля компонентов.

Компоненты UI-библиотеки в Options API нужно **регистрировать** (неделя 3, день 1):

```js
import Button from 'primevue/button'

export default {
  components: { Button },
}
```

А `useDark` — композабл, поэтому в Options API — через `setup()`:

```js
import { useDark, useToggle } from '@vueuse/core'

export default {
  setup() {
    const isDark = useDark()
    return { isDark, toggleDark: useToggle(isDark) }
  },
}
```

Если на работе UI-библиотека зарегистрирована **глобально** (`app.component('Button', Button)` в `main.js`), то в компонентах её можно использовать без импорта и без `components`. Посмотри `main.js` рабочего проекта — там будет видно.
