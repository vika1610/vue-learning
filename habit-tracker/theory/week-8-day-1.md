# Занятие 1. Данные для графика

## Разминка (5 мин): массивы и даты

Повтор недель 0 и 4. Как получить массив `[0, 1, 2, …, 13]` без цикла `for`?

<details>
<summary>Ответ</summary>

```js
Array.from({ length: 14 }, (_, i) => i)
```

`Array.from` создаёт массив заданной длины и для каждого элемента вызывает функцию (как `map`). `_` — принятое имя для неиспользуемого параметра (здесь — текущий элемент, он всё равно `undefined`), `i` — индекс.

Другой вариант: `[...Array(14).keys()]`.

</details>

## Часть 1. Что рисуем

**Столбчатый график**: по горизонтали — последние 14 дней, по вертикали — сколько привычек выполнено в этот день.

```
 4 │        █
 3 │  █     █  █
 2 │  █  █  █  █     █
 1 │  █  █  █  █  █  █  █
   └──────────────────────────
     23 24 25 26 27 28 29 …
```

Графику нужны **два массива** одинаковой длины:

```js
labels: ['23 окт', '24 окт', '25 окт', …]   // подписи по горизонтали
data:   [3, 2, 4, 3, 1, 2, …]               // значения
```

Главная работа сегодня — не нарисовать график (это сделает библиотека), а **подготовить** эти два массива из `doneDates` всех привычек.

## Часть 2. Последние 14 дней

Нужен массив дат-ключей от 13 дней назад до сегодня:

```
['2026-10-23', '2026-10-24', …, '2026-11-05']
```

Инструменты:
- `Array.from({ length: 14 }, (_, i) => …)` — из разминки;
- «день назад» — `setDate(getDate() - n)` (неделя 6, день 4) — **на копии** даты!
- `toDateKey(date)` — твоя утилита.

Подумай, какой `n` нужен для `i = 0` (самый старый день) и для `i = 13` (сегодня).

Это **чистая функция** — `lastDays(count, today)`. Положи её в `utils/date.ts` и напиши на неё тест: ты уже умеешь (неделя 7, день 3). Особенно — на переход через начало месяца.

## Часть 3. Сколько выполнено в каждый день

Для каждого дня из списка — сколько привычек содержат его в `doneDates`:

```js
const counts = days.map((day) =>
  habits.filter((h) => h.doneDates.includes(day)).length,
)
```

`map` по дням, внутри — `filter` по привычкам и `length`. Методы массивов из недели 0 делают всю работу.

### Подписи

```js
const labels = days.map((day) =>
  fromDateKey(day).toLocaleDateString('ru-RU', { day: 'numeric', month: 'short' }),
)
// ['23 окт.', '24 окт.', …]
```

### Всё — в `computed`

```js
const chartData = computed(() => {
  const days = lastDays(14)
  return {
    labels: days.map(/* подписи */),
    datasets: [
      {
        label: 'Выполнено привычек',
        data: days.map(/* подсчёт */),
      },
    ],
  }
})
```

Это формат, который понимает Chart.js: `labels` и массив `datasets` (наборов данных — можно несколько линий на одном графике).

`computed` — значит, при отметке привычки график **пересчитается сам**.

# Занятие 2. График

## Часть 4. Установка

```bash
npm install chart.js vue-chartjs
```

- **Chart.js** — сама библиотека графиков, на обычном JavaScript;
- **vue-chartjs** — обёртка: готовые Vue-компоненты `<Bar>`, `<Line>`, `<Pie>`…

## Часть 5. Компонент графика

```vue
<!-- components/DoneChart.vue -->
<script setup lang="ts">
import { Bar } from 'vue-chartjs'
import {
  Chart as ChartJS,
  BarElement,
  CategoryScale,
  LinearScale,
  Tooltip,
  Legend,
} from 'chart.js'

ChartJS.register(BarElement, CategoryScale, LinearScale, Tooltip, Legend)

defineProps<{
  data: { labels: string[]; datasets: { label: string; data: number[] }[] }
}>()

const options = {
  responsive: true,
  maintainAspectRatio: false,
  scales: {
    y: { beginAtZero: true, ticks: { precision: 0 } },
  },
}
</script>

<template>
  <div class="chart">
    <Bar :data="data" :options="options" />
  </div>
</template>

<style scoped>
.chart {
  height: 300px;
}
</style>
```

```vue
<!-- StatsPage.vue -->
<DoneChart :data="chartData" />
```

Разбор:
- **`ChartJS.register(...)`** — Chart.js по умолчанию «пустой»: подключаешь только нужные части (столбцы, оси, подсказки). Так в сборку не попадает лишний код;
- **`<Bar :data :options />`** — обычный Vue-компонент с props. `data` — твой `computed`;
- **`beginAtZero`** — ось Y с нуля; **`precision: 0`** — без дробных делений («2,5 привычки» не бывает);
- **`maintainAspectRatio: false`** + высота у обёртки — график занимает заданную высоту, а не растягивается как попало.

`DoneChart` — «тупой» компонент: получает данные через props и рисует. Данные готовит страница. Так его можно переиспользовать для другого графика.

## Часть 6. Подводные камни

### ⚠️ «… is not a registered scale / element»

Если в консоли ошибка вида *"category" is not a registered scale* — забыла зарегистрировать часть Chart.js в `ChartJS.register(...)`. Для `<Line>` нужны `LineElement` и `PointElement`, для `<Pie>` — `ArcElement`.

### ⚠️ График не обновляется

vue-chartjs следит за **новым объектом** `data`. Если `chartData` — `computed`, который каждый раз возвращает новый объект, всё работает. А если ты меняешь массив **внутри** старого объекта (`chartData.datasets[0].data.push(...)`), график может не заметить. Держи данные в `computed` — и проблемы не будет.

### ⚠️ Цвета и тёмная тема

Chart.js рисует на `<canvas>`, а не HTML-элементами. Поэтому CSS-переменные (неделя 7, день 5) на него **сами не действуют**. Цвет столбцов задаётся в `datasets`:

```js
{ label: '…', data: […], backgroundColor: '#42b883' }
```

Для тёмной темы цвет текста осей можно взять из `isDark` (`useDark`) и передать в `options`. Это бонус.

### Ленивая загрузка

Chart.js — тяжёлая библиотека. Страница «Статистика» у тебя уже ленивая (неделя 5, день 5): `component: () => import('../pages/StatsPage.vue')`. Значит, Chart.js загрузится только при переходе на неё. Проверь во вкладке Network.

## Часть 7. 📜 Как это в Options API

vue-chartjs работает одинаково. Компонент графика на Options API:

```js
import { Bar } from 'vue-chartjs'

export default {
  components: { Bar },              // ⚠️ регистрация
  props: {
    data: { type: Object, required: true },
  },
  data() {
    return {
      options: { responsive: true, scales: { y: { beginAtZero: true } } },
    }
  },
}
```

А данные для графика на странице — в опции `computed`, через `this.habits` (из `mapState`). Логика `lastDays`, подсчёта и подписей — те же чистые функции.
